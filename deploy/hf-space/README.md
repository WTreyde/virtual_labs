# LabForge: digital twins of autonomous labs

Describe the autonomous lab you want. An agent designs it from real vendor equipment, lays it out,
simulates its throughput and tells you which of its own numbers it doesn't trust.

This public demo is **replay-only**: the two case studies are recorded agent runs, and the benchmark,
validation and schedule views are computed live from the committed data. Live design needs an API key
and is turned off here. Source: https://github.com/WTreyde/virtual_labs
